## Coding Conventions

### Naming Rules

| Target | Convention | Example |
|--------|-----------|---------|
| Classes | PascalCase | `AdminPageController`, `WeeklyAiInsightService` |
| Methods/Fields | camelCase | `getUserById`, `handleSubmit` |
| Constants | UPPER_SNAKE_CASE | `MAX_RETRY_COUNT`, `API_TIMEOUT` |
| DTO/Entity | PascalCase + suffix | `WeeklyAiInsightViewDTO`, `WeeklyAiInsight` |
| Packages | lowercase | `com.dailydevinsight.admin.service` |

### Layered Architecture

| Layer | Location | Responsibility | Can Import |
|-------|----------|----------------|------------|
| **Controller** | `controller/`, `admin/controller/` | HTTP endpoints, request/response mapping | Service, DTO |
| **Service** | `service/`, `admin/service/` | Business logic | Repository, Entity, DTO |
| **Repository** | `repository/` | Data access (JPA) | Entity |
| **Entity** | `entity/` | Domain model / persistence | Nothing (independent) |
| **DTO** | `dto/`, `admin/dto/` | Data transfer between layers | Entity (mapping only) |
| **Config** | `config/` | Framework/infra configuration | - |

### Additional Conventions

- Package root: `com.dailydevinsight`
- Admin-specific code lives under `admin/` (controller, service, dto)
- Static resources: `src/main/resources/static/`, templates: `src/main/resources/templates/`

## Verification Discipline (Audit + Anchor)

> `docs/portable-agent-rules.md`의 Audit Discipline(§2)/Anchor Discipline(§5)에서
> 이 프로젝트의 Claude+Codex 교차검증 워크플로우에 실제로 적용 가능한 부분만 뽑아 압축.
> 전체 원문·근거는 해당 파일 참고.

### 검증 범위 선언 (Audit)
- 검증(리뷰) 작업을 시작할 때 **검사하지 않는 범위를 한 문장으로 먼저 선언**한다 (예: "테스트 실제 실행은 안 함").
- 선언 안 한 범위에서 나중에 문제가 발견되면 새 이슈가 아니라 **스코프 누락**으로 기록한다.
- 수정(fix) 후에는 같은 파일/연관 파일에서 함께 유지되어야 하는 다른 주장도 같이 확인한다 (회귀 확인).
- 다른 곳에 인용될 산출물(설계 문서, 완료 보고서 등)은 **외부 교차검증 필수** — 이 프로젝트에서는 Claude 작성 → Codex 검증(또는 반대)이 그 역할을 한다.

### 원본 취지 고정 (Anchor)
- Plan → Design → Report처럼 여러 문서를 거치는 작업에서, 사용자가 원래 말한 핵심 요구사항이 뒤로 갈수록 축소·누락되지 않았는지 매 단계 확인한다.
- **Claude와 Codex가 서로 합의했다고 검증이 끝난 게 아니다** — 둘 다 LLM 기반이라 같은 사각지대를 공유할 수 있다. 실질적 영향을 주는 반영은 사용자 승인을 거친다.
- 이전 턴에서 지켰던 규율(스코프 선언, 외부검증 등)이 다음 턴에서 슬그머니 빠지지 않았는지 스스로 점검한다.
