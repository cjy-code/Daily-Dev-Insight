# 관리자 콘솔 UI/UX 전면 개편 (Admin UI Overhaul) Planning Document

> **Summary**: 관리자 콘솔 전반의 레이아웃/컴포넌트가 여백 과다·구식 톤으로 답답해 보인다는 피드백 — 타일(카드) 기반 레이아웃 등으로 전면 재설계 검토가 필요하나, 범위가 크므로 지금은 착수하지 않고 백로그로만 남긴다
>
> **Project**: dailyDevInsight
> **Date**: 2026-08-30
> **Status**: Backlog (착수 보류 — 사용자가 "지금은 유지, 나중에 확인해서 개선"으로 명시)

## 1. Overview

### 1.1 배경

- [[admin-posts-table-actions-overflow]] (작업 컬럼 잘림 CSS 수정)를 실제 로그인 화면(`admin01`/`1234`, 로컬 Docker Oracle+Redis)에서 확인하던 중, 사용자가 스크린샷을 보고 컬럼 잘림 문제 외에 전반적인 UI 밀도/여백/톤에 대한 불만을 제기함
- 구체적으로 언급된 것: 버튼/전반 UI가 "답답함", 콘텐츠 대비 남는 여백이 과다, 전체적으로 "후져 보임", 타일(카드) 기반 레이아웃으로 갈아엎는 것을 고려 중
- 다만 작업 범위가 클 것으로 예상되어 지금 바로 착수하지 않고, 나중에 시간 내서 확인 후 개선하기로 함 — 이 문서는 그 시점에 컨텍스트를 잃지 않기 위한 기록

### 1.2 참고

- 현재 관리자 레이아웃 골격: `.admin-shell`(260px 사이드바 + `1fr` 콘텐츠 grid), `.admin-panel`(흰 배경 카드, `overflow-x: auto`), `.admin-table`(표 기반 목록)
- 콘텐츠 영역은 `.layout-container { max-width: 1200px; }`(`layout.css`)에 의해 상한이 걸려 있음 — 이번에 확인한 실제 화면에서도 표 아래/옆으로 빈 공간이 크게 남는 것이 눈에 띔
- 관련 스타일 파일: `backend/src/main/resources/static/css/admin.css` (전역), `layout.css` (공통 셸)

## 2. Scope (착수 시점에 확정할 것)

### 2.1 다뤄볼 후보

- [ ] 관리자 화면 전반의 여백/밀도 재조정 (패딩, 카드 간격, 빈 공간 비율)
- [ ] 목록 화면(게시물/회원 관리 등)을 표 대신 카드/타일 레이아웃으로 전환할지 검토
- [ ] 버튼 톤/스타일(현재 브랜드 컬러 단색 버튼) 재검토
- [ ] 대시보드/통계 등 표가 아닌 화면도 함께 톤 정합성 확인

### 2.2 Out of Scope (이번 백로그 등록 시점 기준)

- 실제 CSS/템플릿 수정 — 착수 시점에 별도 Plan 문서로 재작성
- [[admin-posts-table-actions-overflow]]에서 이미 처리한 작업 컬럼 잘림 수정 (완료됨, 본 문서와 별개)

## 3. Next Steps

1. [ ] 착수 시점에 사용자와 함께 "답답하다"고 느낀 화면 스크린샷을 다시 수집하고, 구체적으로 어떤 요소(여백/버튼/표 구조) 때문인지 짚어본다
2. [ ] 타일 기반 레이아웃 등 대안 시안을 1~2개 스케치해서 사용자 확인
3. [ ] 범위(전체 admin vs 우선순위 화면)와 착수 순서를 정해 별도 Plan 문서로 분리 작성
