# Daily Dev Insight MVP 범위 정의

## 1. 목적

- 초기 릴리즈에서 범위 과다를 방지한다.
- 핵심 사용자 가치인 "오늘의 지식/뉴스 확인"과 "날짜별 조회"만 제공한다.

## 2. MVP 포함 기능 (5개)

### F1. 오늘의 지식 1개 조회
- 설명: 특정 날짜 기준 대표 지식 콘텐츠 1건을 제공한다.
- 화면/API 기준:
  - 메인 화면 상단에 "오늘의 지식 1개" 고정 영역 노출
  - API로는 단건 또는 리스트 첫 요소로 제공
- 완료 기준:
  - 날짜별로 최대 1건만 반환된다.
  - 제목, 링크, 요약, 출처, 발행일을 확인할 수 있다.

### F2. 오늘의 뉴스 리스트 조회
- 설명: 특정 날짜 기준 개발 뉴스 목록을 제공한다.
- 화면/API 기준:
  - 메인 화면에 뉴스 리스트 렌더링
  - 기본 정렬은 최신순
- 완료 기준:
  - 0건 이상 정상 반환된다.
  - 각 항목에 제목, 링크, 출처, 발행일이 포함된다.

### F3. 날짜별 조회
- 설명: 사용자가 선택한 날짜(`yyyy-MM-dd`) 기준으로 지식/뉴스를 조회한다.
- 화면/API 기준:
  - 날짜 선택 입력 제공
  - 선택 날짜로 재조회 수행
- 완료 기준:
  - 유효한 날짜 입력 시 해당 날짜 결과를 반환한다.
  - 데이터가 없으면 빈 결과와 안내 메시지를 제공한다.

### F4. 기본 조회 API 제공
- 설명: 프론트가 사용할 최소 API를 제공한다.
- 필수 API:
  - `GET /api/insights?date=yyyy-MM-dd`
- 완료 기준:
  - `date` 미입력 시 서버 기준 오늘 날짜로 조회한다.
  - JSON 스키마가 문서와 일치한다.

### F5. 최소 오류 처리 및 빈 상태 처리
- 설명: 사용자 경험을 해치지 않도록 최소 예외/빈 상태를 처리한다.
- 완료 기준:
  - 잘못된 날짜 형식 요청 시 400 응답
  - 서버 오류 시 500 응답
  - 프론트에서 로딩/오류/빈 목록 상태를 구분해 표시

## 3. MVP 제외 기능 (초기 범위 밖)

- 추천 기능
- 알림 기능
- 관리자 페이지

## 5. 수용 기준 (Acceptance)

- 사용자 시나리오 3개가 모두 동작하면 MVP 완료로 본다.
  - 오늘 접속 시 대표 지식 1개와 뉴스 리스트를 볼 수 있다.
  - 날짜를 바꿔 해당 날짜 데이터로 조회할 수 있다.
  - 데이터가 없는 날짜에서도 오류 없이 빈 상태 안내를 볼 수 있다.
