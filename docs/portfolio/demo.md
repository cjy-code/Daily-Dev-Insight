# DailyDevInsight 시연 화면

> 목적: Notion은 짧은 포트폴리오 요약으로 유지하고, 상세 시연 화면과 GIF 촬영 계획은 GitHub에서 관리한다.
> Notion 요약: https://app.notion.com/p/DailyDevInsight-RSS-AI-3b8806eb2ec081d6be8fd464578b8f4e

이 문서는 포트폴리오용 시연 화면을 기능 흐름별로 정리한다. Notion에는 모든 스크린샷과 GIF를 붙이지 않고, 대표 설명과 이 문서 링크만 둔다.

## 1. 홈 피드

![홈 피드](../images/screen-main.jpg)

사용자 첫 화면에서 오늘의 지식, 기술 뉴스, 일일 개발 트렌드가 함께 노출되는 흐름을 보여준다.

보여주는 가치:

- 관리자가 아닌 일반 사용자가 보는 서비스 핵심 화면이다.
- RSS 수집 결과와 AI 생성 학습 콘텐츠가 한 화면에서 연결된다.
- 포트폴리오 첫 시연으로 사용하면 서비스가 무엇을 하는지 빠르게 설명할 수 있다.

## 2. 인사이트 상세

![인사이트 상세](../images/screen-detail.jpg)

상세 조회, 조회수, 좋아요, 북마크, 댓글, 대댓글 흐름을 보여준다.

보여주는 가치:

- 단순 배치/관리자 도구가 아니라 사용자 참여 화면까지 구현되어 있음을 보여준다.
- SSR 최초 렌더링과 JavaScript 재렌더링이 같은 댓글 트리 구조를 사용한다.
- 삭제된 댓글은 placeholder로 남겨 대댓글 맥락이 끊기지 않는다.

## 3. 관리자 크롤링과 일일 트렌드

![관리자 크롤링과 트렌드](../images/screen-admin-crawling.jpg)

관리자 화면에서 크롤링 조건 프리셋, 수동 크롤링, 실행 이력, 일일 트렌드 생성을 관리하는 흐름을 보여준다.

보여주는 가치:

- 관리자가 코드 수정 없이 RSS 수집 조건을 운영할 수 있다.
- 일일 트렌드 생성이 숨은 배치가 아니라 관리자 워크플로우로 노출된다.
- 성공/실패 이력을 확인할 수 있어 운영 관점의 추적성이 있다.

## 4. AI 생성 흐름

상태: 실제 GIF 또는 스크린샷 추가 예정

촬영할 흐름:

- 관리자 생성 화면 진입
- 프롬프트 템플릿 선택 또는 검토
- 일일 지식 생성 결과 미리보기
- 저장 전 제목, 요약, 본문 수정
- 저장 후 사용자 화면 노출 확인

보여줄 가치:

- OpenAI 결과를 바로 게시하지 않고 관리자가 검토한다.
- 미리보기, 수정, 저장, 공개 화면 확인의 단계를 분리했다.
- AI를 단순 생성 버튼이 아니라 운영 가능한 콘텐츠 생성 흐름으로 다룬다.

## 5. 일일 트렌드 인사이트 흐름

상태: 실제 GIF 또는 스크린샷 추가 예정

촬영할 흐름:

- 기준일 뉴스 수집 또는 기존 뉴스 확인
- 일일 개발 트렌드 생성
- 관리자 크롤링 화면에서 키워드와 요약 확인
- 일일 지식 생성 화면에서 트렌드 참고 영역 확인
- 지식 콘텐츠 저장 후 홈 화면 노출 확인

보여줄 가치:

- `RSS 뉴스 -> 일일 트렌드 -> 일일 지식 프롬프트 -> 사용자 콘텐츠` 흐름을 한 번에 설명할 수 있다.
- 현재 서비스의 차별점을 가장 명확하게 보여주는 시연이다.

## GIF 촬영 우선순위

1. Home Feed: 10~15초
2. Insight Detail 참여 기능: 15~20초
3. Admin Crawling과 트렌드 생성: 20~25초
4. AI Generation 미리보기부터 저장까지: 20~25초
5. 일일 트렌드와 일일 지식 연결: 20~30초

Notion에는 대표 이미지 또는 GIF 1개만 두고, 나머지 기능별 시연은 이 문서에서 관리한다.
